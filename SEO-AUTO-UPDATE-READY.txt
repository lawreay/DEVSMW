## 🔧 Technical Implementation

### Cache Control Strategy
```
Public Pages (5 min)       → Quick browser cache + fresh for search engines
├─ index.php
├─ profile.php
└─ profiles.php

Sitemap (24 hours)         → Reduces server load, still responsive
└─ sitemap.xml.php

Admin Pages (no cache)     → Always fresh, never stale
├─ dashboard.php
├─ profile_edit.php
├─ login.php
└─ change_password.php

Static Assets (30 days)    → CSS, JS, images rarely change
└─ assets/*
```

### Database Timestamps
```php
// Automatic on every profile edit
$update = db()->prepare('UPDATE profiles SET bio = ?, updated_at = NOW() WHERE id = ?');
```

### Fresh Data Generation
```php
// Every page load gets fresh data
$stmt = db()->prepare('SELECT * FROM profiles WHERE github_username = ?');
$stmt->execute([$username]);
$profile = $stmt->fetch();  // ← Fresh from database

// Meta tags generated from that fresh data
<?= meta_description($profile['bio']) ?>
<?= schema_person($profile) ?>
```
