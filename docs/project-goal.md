# Project Goal

DEVSMW Profiles is a searchable directory of Malawi developers and technology contributors.

The goal is to make public developer information easier to discover while respecting privacy, platform rules, and the rights of each person listed.

## Core Objectives

* Show searchable developer profiles.
* Store profile data in MySQL.
* Allow admins to edit profile records.
* Allow admins to refresh GitHub data with one click.
* Track data sources for accountability.
* Keep private, sensitive, or disputed data out of public view.
* Provide opt-out and correction processes.

## Data Sources

Preferred sources:

* GitHub public profile and repository API.
* Data supplied directly by the profile owner.
* Public personal websites.
* Public organisation pages where reuse is permitted.
* Search engine result links reviewed by an admin.

Restricted sources:

* LinkedIn should not be scraped automatically. Add LinkedIn URLs manually or through an official/approved integration.
* Do not bypass robots.txt, login walls, rate limits, CAPTCHAs, or platform access controls.
* Do not collect private data from leaked files, private repositories, or non-public messages.

## Success Definition

The app is successful when visitors can search profiles quickly, admins can keep records accurate, and profile owners can request edits or removal without friction.
