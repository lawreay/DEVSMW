# Data Rules

These rules are part of the product design, not optional admin advice.

## Collection Rules

* Collect the minimum data needed for a useful developer profile.
* Prefer public GitHub API data over page scraping.
* Do not collect national ID numbers, home addresses, private messages, private repository data, passwords, or sensitive personal data.
* Do not publish phone numbers or email addresses unless they are clearly public or supplied by the profile owner.
* Do not infer sensitive traits such as religion, ethnicity, health, political views, or sexuality.
* Do not present guesses as facts.

## Source Rules

* Store a source URL for manually added data.
* Mark uncertain data as `needs_review`.
* Keep copied text short and prefer summaries.
* Respect robots.txt, platform Terms of Service, API rate limits, and access controls.

## GitHub Rules

Use the GitHub API where possible. GitHub states that API use is subject to its Terms of Service and Privacy Statement, and its acceptable use policy distinguishes API collection from scraping. Do not use GitHub data for spam, resale of personal information, recruiter spam, or similar misuse.

Sources:

* https://docs.github.com/site-policy/github-terms/github-terms-of-service
* https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies

## LinkedIn Rules

Do not automate scraping from LinkedIn. LinkedIn states that prohibited tools and automated activity can violate its User Agreement and may lead to account restrictions.

Approved options:

* Let admins paste a LinkedIn URL manually.
* Let profile owners submit their own LinkedIn URL.
* Use an official approved LinkedIn integration if one becomes available.

Sources:

* https://www.linkedin.com/legal/user-agreement
* https://www.linkedin.com/help/linkedin/answer/a1341387
* https://www.linkedin.com/help/linkedin/answer/a1340567

## Malawi Data Protection Rules

Malawi's Data Protection Act, 2024 regulates processing of personal data and gives rights to data subjects. Treat every profile as personal data and support correction, deletion, source review, and opt-out requests.

Sources:

* https://www.dpa.mw/download/data-protection-act-2024/
* https://www.africadataprotection.org/en/pays/malawi.html

## Admin Rules

* Keep admin accounts private.
* Change the default admin password before launch.
* Review edits before publishing.
* Hide a profile immediately when a credible complaint is received.
* Keep notes factual and professional.
* Never add defamatory, mocking, private, or speculative content.
