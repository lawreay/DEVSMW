# Privacy Policy

Last updated: 12 August 2026

This policy is a starter document and should be reviewed by a qualified lawyer before public launch.

## Data We Store

DEVSMW Profiles may store:

* GitHub username and profile URL.
* Public name.
* Public location.
* Public work/company.
* Public website and project links.
* Public email or phone only when clearly available or submitted.
* Profile bio, skills, and project summaries.
* Source URLs and admin notes.

## Why We Store It

We store this data to operate a searchable developer directory, support community discovery, and help profile owners present their work.

## Data Sources

Sources may include GitHub public API data, public websites, admin-reviewed search results, and data submitted by profile owners. LinkedIn content should not be scraped automatically.

## Corrections and Opt-Out

Profile owners can request correction, update, hiding, or deletion of their profile. Admins should act promptly and keep a record of the request.

## Data Minimisation

Admins should avoid collecting data that is unnecessary, sensitive, private, or risky. Missing data should remain blank or display `Not publicly available`.

## Security

Admins should use strong passwords, limit database access, keep backups secure, and avoid sharing exported profile data unless there is a lawful and legitimate reason.

## Retention

Profiles should be kept only while they remain useful, accurate enough, and lawful to display. Opted-out profiles should be hidden or deleted according to the request and legal advice.
